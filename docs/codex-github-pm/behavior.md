# 記録方針と検証

[概要](README.md) · [使い方](usage.md) · [導入手順](installation.md)

## 現在の方針

v1.3.1では、GitHub管理の依頼を自然に受け取り、必要な接続支援を提案し、記録は重要な新情報に絞ります。

| 判断 | 方針 |
|---|---|
| スキルを使うか | 会話やリポジトリからGitHubが対象と分かれば、進捗・残タスク・優先順位・障害の依頼にも適用 |
| 接続支援が必要か | 未ログイン、接続手段不足、対象不明など、確認できた不足だけ支援を提案。準備後は元の依頼へ戻る |
| コメントを残すか | 共有価値・既存記録との重複・依頼範囲を確認。不要なら下書きや投稿確認も作らない |
| どう書くか | 目的・変更点・確認結果・次の行動を具体的に伝え、完了条件と重要な制約を保つ |

人の判断が必要な障害、合意した方針・範囲変更、必要な引き渡しをまとめます。
調査開始・再試行・個々のテスト成功を連投せず、関連PRで十分伝わる成果も転載しません。
定例は明示依頼または合意済み運用がある場合だけ扱い、変化がなければ原則投稿しません。
明示された「変化なしの報告」は例外です。記録先がないだけで定例Issueを探したり作成を提案したりしません。

文章と投稿判断の正本は、Skill内の`references/writing-and-tracking.md`です。
スキル本体・操作手順・定例手順から同じ資料を参照します。
具体的な利用例と記録のタイミングは[使い方](usage.md)を参照してください。

## 追加した内容

- **v1.3.0**：自然な起動条件を補強し、投稿の必要性を先に判断する手順と、読みやすい文章のルールを追加。
- **v1.3.1**：依頼中に不足が判明したときの接続支援を追加。既知の情報や許可済みの準備を再質問せず、代行できなければ利用者側の具体的な操作を案内。

接続支援は専用の初期設定機能や自動ログインではありません。
接続準備への許可をIssue投稿などへ広げず、準備の経過もIssueには記録しません。

## 検証方法

### オフラインテスト

```bash
bash install_codex_github_pm.sh --self-test
```

隔離した一時環境で、導入・更新・解除・読み取り補助・静的な指示の整合性を検証します。
実GitHubへの書き込み、モデルの起動判断、文章の読みやすさを証明するテストではありません。

### モデルの会話検証

`--extract`で展開した`tests/behavioral-scenarios.md`に、17件の固定入力と期待結果があります。
起動、投稿判断、文章、接続支援を、架空の資料と読み取り・文案作成の依頼で確認するためのものです。
このシナリオは`--self-test`によってモデル上で自動実行されるものではありません。

起動例は新規セッションで試し、入力にスキル名や期待動作を混ぜません。
投稿判断では不要な記録の省略と、障害・範囲変更の保持を確認します。
文章では文字数や表現の完全一致より、情報の保持・重複・未合意事項の捏造を実際に読みます。
接続支援では、不足だけを尋ね、既知の情報や許可済みの準備を聞き直さないことを確認します。

## 確認済みの結果

以下は2026-10-03に確認した結果です。

| 対象 | 検証と結果 |
|---|---|
| v1.3.0・v1.3.1の配布物 | オフラインテスト各99件、Bash構文、文書のローカルリンク、差分の空白検査が成功 |
| 導入済み資材 | 配布物との一致、共通AGENTSの既存文章保持、通常再実行で内容・更新時刻が変わらないこと、診断結果を確認 |
| v1.3.0の起動 | 独立した5セッション。日英の管理依頼3件でSkillを実際に読み、ローカル誤字確認・出典表記だけの2件では読まなかった |
| v1.3.0の投稿判断（B05〜B10） | 途中経過・既出成果・変化なし・フィールド更新の追加コメントを省略。障害と範囲変更を保持し、継続承認を再要求しなかった |

| v1.3.1の接続支援 | 新規セッションの架空7ケースで、ログイン・CLI導入の提案、対象質問、接続済み時の調査開始、MCP再利用、再承認の省略、利用者側の操作案内を確認 |

既存の文章支援スキルも参照されており、本スキル単独の品質測定ではありません。

実際のログイン・CLI導入・GitHubへの投稿や変更、既存Issueの一括整理は、この会話検証では行っていません。
発火率、投稿削減率、実運用での文章改善効果も未測定です。
上の結果は各例での動作確認として扱い、実認証フローの完了や常に正しい判断を保証するものではありません。
