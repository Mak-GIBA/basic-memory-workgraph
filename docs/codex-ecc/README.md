# Codex ECCのスキルを必要なときに読む

[docs一覧](../README.md) · [導入手順](installation.md) · [使い方](usage.md)

ECCをCodex標準のプラグインとしてインストールし、常設スキルを4つの短い入口に絞ります。
原本を保持したまま、Python実装・エラー処理・安全性レビューに使う手順を参照できます。
その他の専門スキルは、作業に合うものを検索して読みます。

[install_codex_ecc.sh](../../install_codex_ecc.sh)は、`tools/ecc-on-demand/`を含むリポジトリ一式で使います。
引数なしでは通信せず予定を表示し、`--apply`で実際に導入します。

## 導入するツールと役割

| ツール・資材 | 提供元 | 用途・導入条件 |
|---|---|---|
| ECCプラグインの原本 | `affaan-m/ECC` | Codex標準の機能から未導入時に取得。導入済みなら再利用 |
| ECCの入口4件 | このリポジトリ | 作業に必要な原本を取得するユーザー用スキル |
| 管理CLI | このリポジトリ | 適用・診断・検索・原本取得・更新・復元 |

ECCは外部提供のプラグインです。原本の取得と更新にはCodex標準のプラグイン機能を使います。
インストール後はECCプラグインを無効にし、スキルの一括登録、付属の起動フックとMCPを停止します。
Basic Memoryと独立して設定したMCPは維持します。

## 読む順序

1. [導入手順](installation.md)で前提条件・変更内容を確認する。
2. [使い方](usage.md)で入口から原本を取得する。
3. 詳しい管理CLIと停止する機能は、[ECCを必要なときに読む](../ecc-on-demand.md)を参照する。

## 参照資料

導入手順は、2026-10-03時点のCodex CLI 0.160.0と、導入済みECC 2.2.3で確認したネイティブのコマンド体系に基づきます。
利用可能な版や原本の場所は、実行時のCodexカタログから取得します。
配布元は[ECC](https://github.com/affaan-m/ECC)です。
