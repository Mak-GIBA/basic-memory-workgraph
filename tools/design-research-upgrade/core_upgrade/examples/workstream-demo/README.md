# 検討計画の合成例

検索系システムの要件から3つの検討テーマを切り出す例です。
データ、手法の優劣、実行済みの研究run、ユーザー承認は含みません。
RP1とRP2は固定入出力で独立探索可能、RP3は両方の実結果に依存します。
最終統合は各ローカル最良案の単純な足し合わせではありません。

パッケージのoverlay/tools/design-research/skill/scripts/research_workstreams.pyに対して、
plan .specify/workbench/research-plan.json --project <このディレクトリ> を実行できます。
