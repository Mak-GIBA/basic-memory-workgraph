# 留保を減らし、確信度は変えない

不要なのは、文章を読んでも判断が変わらない予防線である。「あくまで参考ですが」「一概には言えませんが」を文書全体へ繰り返す代わりに、結論の根拠と適用範囲を書く。条件がすでに示されているなら同じ条件の再掲を減らす。

一方、推定・観測・仮説の違いは内容そのものである。観測データの関連を因果に変えない。「有意差を確認できなかった」を「効果がない」に変えない。「一部の条件で」を消して全条件への主張にしない。「予定」を「実施済み」に変えない。

変更例：
「結果から効果がある可能性が示唆されると考えられる」→「結果は効果の可能性を示唆する」。
「今回の環境に限った結果であり、一般化はできません。CPU環境は未評価です」→「CPU環境は未評価であり、結果を適用できる範囲は今回の環境に限られる」。
元の環境がGPUであるとは書かれていないため、GPUという事実は加えない。重複した婉曲表現を一段にしても、未確定を確定にしない。

安全上の条件、法的な義務、科学的な限界、読者に必要な注意は削らない。一律の免責を末尾へ追加することもしない。誤読を防ぐ最短の形を選び、関連する主張のすぐ近くに置く。
