# 執筆結果の点検

機械検査は候補の発見と表記の照合を担当し、意味・論証・読者適合は全文のレビューで判断する。検査の0件や100点を文章品質の証明にしない。

読む順序：完成稿だけで独立読解→段落主文だけで論旨→各主文と説明の対応→素材と完成稿の意味照合。推敲では保持対象が抜けていないか、新しい判断が増えていないかを確認する。新規執筆では、各主要主張が素材・出典・明示した推論のどれに支えられているかを確認する。

品質の基準は、読者適合、段落の統一性、主張と根拠の対応、文章全体のつながり、日本語の自然さ、意味・情報量の保持の6軸である。重大な事実変更や指示者向け説明の混入があれば、平均点が高くても完成としない。必要な修正箇所と短い根拠を記録し、思考過程の逐語記録や自己賛辞を求めない。

上流更新時は `--check-update` で版を確認し、更新後の `--doctor` と `--self-test` を実施する。自己テストはインストーラーと独自検査の挙動を確認するもので、Codexの執筆品質を計測するものではない。文章品質の比較には同梱の評価用課題と、実際のCodex実行結果を用いる。
