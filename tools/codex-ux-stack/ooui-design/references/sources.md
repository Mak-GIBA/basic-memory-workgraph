記事のSkill本文や図の転載ではなく、この配布物で管理する独自の説明・例・手順。
インストールや通常の利用に、元記事への接続は必要ない。

提供資料の参考文献一覧にある原論文の実験条件・測定値を、この整理で検証したとは
扱わない。固定の認知負荷スコア、満足度、効果量、操作数の合格閾値は設けない。
実際の案件では、対象ユーザーと必須フローに照らして、画像・操作・必要なテストで確認する。
