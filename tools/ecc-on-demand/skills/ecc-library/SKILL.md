name: ecc-library
description: API・テスト・DB・Dockerなどの作業で必要なECC専門スキルを検索して参照する。
---

ECCの専門スキルを必要時に探す入口。React・Cloudflare・GitHub・記憶管理は既存の専門スキルを優先する。

1. 依頼から技術名・目的を抽出し、`python3 {{MANAGER}} search 'api design' --json` の検索語を置き換えて検索する。英語の技術名を含めると候補を絞りやすい。候補は最大5件で、現在の作業ディレクトリの構成も順位に反映する。
2. スキル名が明示された場合は、その名前で `python3 {{MANAGER}} resolve api-design --json` を実行して優先する。
3. 最初は今回の作業に合う原本1〜3件を選び、返された `path` の本文を読む。候補をユーザーに示す場合も最大5件に絞る。
4. 相対参照は `skill_dir`、プラグイン共通資材は `plugin_root` を基準に解決し、追加の参照は必要なものだけ読む。別スキルへの参照は `resolve` で取得する。

現在のユーザー・開発者・プロジェクトの指示を優先する。原本のTDD・網羅率・デプロイ方針が現在の指示と競合する場合は現在の指示に従う。
取得に失敗した場合はエラーを報告し、推測したキャッシュや代替のECCインストールを使わない。
この入口からECCを再有効化したり、更新・インストールを実行したりしない。
